# SOC AI Frontend

A modern React-based frontend for the **SOC AI App** — providing real-time dashboards, AI-powered alerts, and interactive tools for Security Operations Centers (SOC).  

This project is inspired by next-gen SOC assistants (like Prophet/Prophete) and focuses on helping analysts detect, investigate, and respond to security incidents faster.  

---

## 🚀 Tech Stack
- **React 18** + **Vite** — Fast frontend framework  
- **TailwindCSS** — Utility-first styling  
- **Shadcn/UI** — Modern accessible components  
- **Recharts / D3.js** — Data visualization  
- **TanStack Router** — Routing  
- **React Query / Axios** — API integration with backend SOC AI services  

---

## 📑 Features
- 🔐 Authentication UI (login, signup, SSO)  
- 📊 Real-time dashboards for alerts & incidents  
- 🧠 AI Assistant panel for SOC queries  
- 📈 Interactive charts & timelines for threats  
- 🔍 Search & filters for logs and alerts  
- 🗂 Playbooks UI to manage response workflows  
- 🌙 Dark mode (SOC-friendly theme)
